# TransDot v1.2.1

- Web 长文字消息复制按钮位于气泡顶部，窄屏点击区域扩大。
- 修复局域网快传新旧连接竞态，网页离开后 Android 等待重新连接；增加原生连接释放保护。
- Web、Android 界面和通知的传输进度最多每 200 毫秒更新一次；完成或失败立即更新。
- 快传界面增加连接同一局域网和 5 GHz Wi-Fi 的指引。
- 新上传图片和附件默认保留 720 小时（30 天）。已有文件到期时间不变；文件池满时拒绝新上传，不提前清理未到期文件。

## 安装与更新

正式 APK 使用与 v1.2.0 相同的签名证书，可覆盖升级；版本号 1.2.1，versionCode 10。

- `TransDot-v1.2.1-arm64-v8a.apk`：适合现代 ARM64 安卓手机。
- `TransDot-v1.2.1-universal.apk`：兼容 arm64-v8a、armeabi-v7a、x86、x86_64。
- 每个 APK 附带同名 `.sha256` 校验文件。

服务端及 Web 也需要更新。如果 `.env` 已设置 `FILE_TTL_HOURS`，请改为 `720`，然后运行项目更新脚本。

## 验证范围

Web、Go 和 Android 单元测试及构建已验证。实际 Android 手机上的闪退日志、断连清理与自动重连，以及双向传输速度提升至少 30% 的验收仍待完成。本版本不声明已达到该速度目标。
