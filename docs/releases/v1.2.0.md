# TransDot v1.2.0

本版本加入多浏览器授权管理，以及面向 Docker/1Panel 部署的一致性备份与安全恢复流程。

## 新增功能

- **多浏览器同时授权**：同一服务器默认可保留 10 个浏览器授权，新增浏览器不再强制替换已有浏览器。
- **设备管理**：Android 可查看浏览器的授权时间与最近活动，支持重命名和逐个撤销；浏览器可修改自己的设备名称。
- **消息来源标识**：Android 与 Web 时间线显示消息来源设备，设备重命名后历史消息同步更新显示名称。
- **实时授权事件**：浏览器新增、重命名和撤销会实时同步；被撤销的浏览器会立即退出。
- **一致性备份**：服务器脚本会短暂停止服务，校验 SQLite 与文件布局，生成包含 manifest 和 SHA-256 的完整归档。
- **安全恢复**：恢复前验证校验和、归档路径、schema、数据库和实例身份，并先在临时卷试恢复；正式覆盖前自动创建安全备份，失败时自动回滚。

## 部署与兼容

- Android 版本为 `1.2.0`，versionCode 为 `9`，要求 Android 6.0 或更高版本。
- 正式 APK 仅连接 HTTPS 服务，并沿用 v1.1.0 的签名证书，可直接覆盖升级。
- 新版客户端连接旧版服务器时保留原有单浏览器替换流程；新版服务器通过 `multi_browser_v1` 能力声明启用多浏览器管理。
- 数据库会自动迁移到 schema 11；普通升级会保留服务器身份、设备授权、消息和文件。
- 默认最多授权 10 个浏览器，可通过 `MAX_BROWSER_DEVICES` 在 1–50 范围内调整。

## 升级

```bash
cd /opt/transdot
sh docker/update.sh
```

使用自定义宿主机端口时，例如 `3366`：

```bash
TRANSDOT_HEALTH_URL=http://127.0.0.1:3366/healthz sh docker/update.sh
```

正常升级不要执行 `docker/reset.sh RESET`，也不要运行 `docker compose down -v`。

## 备份与恢复

创建备份：

```bash
cd /opt/transdot
sh docker/backup.sh /opt/transdot-backups --keep 7
```

恢复备份（归档旁必须保留对应的 `.sha256` 文件）：

```bash
cd /opt/transdot
sh docker/restore.sh /opt/transdot-backups/transdot-backup-YYYYMMDDTHHMMSSZ-FINGERPRINT.tar.gz RESTORE
```

自定义宿主机端口时，同样需要设置 `TRANSDOT_HEALTH_URL`。备份包含服务器身份、设备授权、消息、原始文件和缩略图，不包含 `.env`、证书或临时文件。

## 下载校验

Release 提供两种使用同一正式证书签名的 APK：

- `TransDot-v1.2.0-arm64-v8a.apk`：体积较小，适合绝大多数现代安卓手机。
- `TransDot-v1.2.0-universal.apk`：同时兼容 arm64、32 位 ARM、x86 和 x86_64；不确定设备架构时请选择此包。

每个 APK 均附带同名 `.sha256` 文件。下载后可执行：

```bash
sha256sum -c TransDot-v1.2.0-arm64-v8a.apk.sha256
# 或
sha256sum -c TransDot-v1.2.0-universal.apk.sha256
```
