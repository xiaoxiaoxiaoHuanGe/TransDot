# TransDot v1.1.0

本版本加入局域网点对点文件传输和手机二维码重绑定，并优化 Android 服务器状态展示与自托管更新流程。

## 新增功能

- **局域网快传**：Android 与最新版 Chrome/Edge 在同一局域网时，通过 WebRTC DataChannel 直接传输文件，文件内容不经过云服务器。
- **多文件队列**：Android 和 Web 均可多选文件，按队列逐个传输，并显示连接、进度、完成、失败与取消状态。
- **自动接收目录**：两端首次选择接收文件夹并授权，后续可自动接收；权限失效时会要求重新授权。
- **手机二维码重绑定**：APP 删除或重装后，可在已授权 Web 页面点击“重新绑定手机”，新 APP 扫码后自动恢复服务器连接。
- **凭据安全轮换**：重绑定成功会原子创建新 Android Master 并撤销旧手机凭据；二维码短时、单次有效，刷新后旧二维码立即失效。
- **三行连接状态**：Android 顶部独立显示应用标题、服务器地址和连接状态，长地址自动省略，状态保持完整。

## 部署与兼容

- 普通 Docker 更新会保留服务器身份、设备绑定、消息和文件，不需要重新初始化。
- 新增数据库迁移会在启动时自动执行。
- 公网部署必须配置与实际访问地址一致的 HTTPS `PUBLIC_URL`。
- 局域网快传只使用 Host ICE；访客 Wi-Fi、AP 隔离、VPN 或防火墙可能阻止直连，失败时不会自动转为云端上传。
- Android 要求 Android 6.0 或更高版本；正式 APK 仅允许 HTTPS 服务器。

## 升级

```bash
cd /opt/transdot
sh docker/update.sh
```

使用自定义宿主机端口时，例如 `3366`：

```bash
TRANSDOT_HEALTH_URL=http://127.0.0.1:3366/healthz sh docker/update.sh
```

正常升级不要执行 `docker/reset.sh RESET`，也不要运行 `docker compose down -v`。

## 下载校验

Release 提供正式签名的 `TransDot-v1.1.0.apk` 和对应的 `TransDot-v1.1.0.apk.sha256`。下载后可执行：

```bash
sha256sum -c TransDot-v1.1.0.apk.sha256
```
